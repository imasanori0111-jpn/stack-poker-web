スタックホールデムをホーム画面に追加

ホーム画面に追加すると、アプリのように全画面で遊べます。ストアからのダウンロードは不要・無料です。

iPhone・iPad(Safari)お使いの端末

  1. Safari で、下の ゲームのページ を開く(X や LINE の中のブラウザでは追加できません)
  2. 画面の下(または上)の 共有ボタン(四角から上向きの矢印)を押す
  3. メニューを下へ送り、「ホーム画面に追加」を押す
  4. 右上の 「追加」 を押す

Android(Chrome)お使いの端末

  1. このページを Chrome で開く
  2. 上の「ホーム画面に追加する」ボタンが出ていれば、それを押す
  3. 出ていなければ、右上の ︙(メニュー) から 「アプリをインストール」 または 「ホーム画面に追加」 を押す

ゲストで遊んだデータは、ブラウザごとに別になります。追加する前に、ゲームの「オプション」→「アカウント」で Google を結びつけておくと、同じデータで続けられます。
